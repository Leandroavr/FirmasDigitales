# Firmas Gráficas Personalizadas por Usuario

Coloca en esta carpeta las imágenes que contienen el **Logo de Brascuba + la Firma Escaneada** de cada usuario.

### Formatos soportados:
- `.png` (recomendado, ideal con fondo transparente o blanco)
- `.jpg` / `.jpeg`

### Nombres válidos para los archivos:
El sistema buscará automáticamente la imagen del firmante usando cualquiera de las siguientes convenciones:

1. **Por correo electrónico completo**:
   - `frank.alvarez@brascuba.cu.png`
   - `conrado.peraza@brascuba.cu.png`

2. **Por usuario del correo (antes del @)**:
   - `frank.alvarez.png`
   - `conrado.peraza.png`

3. **Por nombre completo del certificado digital**:
   - `Frank Alvarez Roque.png`
   - `Conrado Peraza Cuevas.png`
   - `frank_alvarez.png`
   - `conrado_peraza.png`

> **Nota**: Si un usuario aún no tiene su imagen colocada en esta carpeta, el sistema utilizará automáticamente el logo corporativo por defecto (`brascuba_logo.jpg`).
